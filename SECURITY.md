# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub private vulnerability
reporting: open the repository's **Security** tab and choose **Report a vulnerability**. The repository owner receives
the report and will answer there.

Include the affected version (`gauss_meridian.__version__`), what you found and how to reproduce it. Never include a
live API key in a report.

## Supported versions

This is a public preview (v0.1.0). Only the latest release receives security fixes.
